================================================
🍓 RASPBERRY PI SETUP & RUN INSTRUCTIONS
================================================

This guide covers running the MediSpecs backend on Raspberry Pi
both LOCALLY (without Docker) and with DOCKER.

================================================
📦 OPTION 1: LOCAL RUN (Recommended for Dev)
================================================

### Step 1: Clone the repository

cd ~
git clone <your-repo-url> medispecs-backend-specs
cd medispecs-backend-specs


### Step 2: Run setup script

chmod +x setup_venv_raspberry_pi.sh
./setup_venv_raspberry_pi.sh

This will:
- Install system dependencies (picamera2, numpy, etc.)
- Create virtual environment
- Link system packages to venv
- Install Python dependencies


### Step 3: Create .env file

nano .env

Add:
LAMBDA_API_URL=https://zqglpdheqk.execute-api.ap-southeast-1.amazonaws.com/staging
USER_ID=u_123

Save: Ctrl+X, Y, Enter


### Step 4: Run the server

source venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

✅ Server running at http://localhost:8000


### To stop:
Press Ctrl+C


================================================
🐳 OPTION 2: DOCKER RUN (Recommended for Prod)
================================================

### Step 1: Clone and prepare

cd ~
git clone <your-repo-url> medispecs-backend-specs
cd medispecs-backend-specs


### Step 2: Create .env file

nano .env

Add:
LAMBDA_API_URL=https://zqglpdheqk.execute-api.ap-southeast-1.amazonaws.com/staging
USER_ID=u_123

Save: Ctrl+X, Y, Enter


### Step 3: Build and run

# Clean build
docker-compose down
docker-compose build --no-cache

# Start services
docker-compose up

# Or run in background
docker-compose up -d


### Step 4: View logs

docker-compose logs -f


### To stop:

# If running in foreground
Press Ctrl+C

# If running in background
docker-compose down


================================================
🎥 CAMERA CONFIGURATION
================================================

The code is configured to:
1. Try picamera2 FIRST (for Raspberry Pi Camera)
2. Fall back to OpenCV (for USB cameras)

Camera Config:
- Resolution: 640x480
- Format: RGB888 (correct colors)
- Auto-detected and initialized on startup

If camera fails, check:
1. Camera is enabled: sudo raspi-config -> Interface -> Camera
2. Camera is connected properly
3. Test with: libcamera-hello (should show preview)


================================================
🔍 TROUBLESHOOTING
================================================

### Issue: "Permission denied: /app"
Solution: You're running locally but code thinks it's Docker
→ Check database.py is using the updated version

### Issue: "Failed to import picamera2"
Solution (Local): Run setup script again
Solution (Docker): Rebuild with --no-cache

### Issue: Camera shows blue colors (Avatar effect)
Solution: Already fixed! Code uses RGB888 format + proper conversion

### Issue: "python-prctl build failed"
Solution (Local): sudo apt-get install libcap-dev python3-dev gcc
Solution (Docker): Already included in Dockerfile

### Issue: YOLO detection not working
Solution: Check YOLO_CONFIDENCE_THRESHOLD in config.py (default 0.65)


================================================
⚙️  CONFIGURATION
================================================

Edit config.py to change:

# Face Detection
FACE_DETECTION_ENABLED = True
FACE_DETECTION_FPS = 2  # Detection rate
FACE_CONFIRMATION_COUNT = 4  # Consecutive detections needed
FACE_COOLDOWN_SECONDS = 10  # Cooldown after recognition
YOLO_CONFIDENCE_THRESHOLD = 0.65  # Detection confidence

# Camera
CAMERA_INDEX = 0  # 0 for default camera

# OLED Display
OLED_ENABLED = True
OLED_BLINK_ON_REMINDER = True
