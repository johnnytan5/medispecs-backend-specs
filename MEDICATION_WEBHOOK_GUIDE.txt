================================================================================
MEDICATION WEBHOOK GUIDE - For Frontend Developers
================================================================================

OVERVIEW:
---------
When a caregiver creates/updates/deletes a medication in the web app, call this
webhook to immediately sync the medication to the Raspberry Pi device.

================================================================================
ENDPOINT
================================================================================

URL: POST /webhook/medications/sync

Via ngrok: 
Via local:  http://localhost:8000/webhook/medications/sync

Method: POST
Headers: Content-Type: application/json (optional, no body needed)
Body: None (empty body is fine)

================================================================================
REQUEST EXAMPLE
================================================================================

JavaScript/TypeScript:
----------------------
async function syncMedications(ngrokUrl) {
  try {
    const response = await fetch(`${ngrokUrl}/webhook/medications/sync`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      }
    });
    
    const data = await response.json();
    
    if (data.status === 'success') {
      console.log(`✅ Synced ${data.syncedCount} medications`);
      return data;
    } else {
      console.error('❌ Sync failed:', data.message);
      throw new Error(data.message);
    }
  } catch (error) {
    console.error('Network error:', error);
    throw error;
  }
}

// Usage
await syncMedications('https://your-ngrok-url.ngrok.io');


cURL:
-----
curl -X POST https://YOUR-NGROK-URL.ngrok.io/webhook/medications/sync


React Hook Example:
-------------------
function useMedicationSync(ngrokUrl) {
  const [syncing, setSyncing] = useState(false);
  const [error, setError] = useState(null);
  
  const syncMedications = async () => {
    setSyncing(true);
    setError(null);
    
    try {
      const res = await fetch(`${ngrokUrl}/webhook/medications/sync`, {
        method: 'POST'
      });
      const data = await res.json();
      
      if (data.status === 'success') {
        return data;
      } else {
        throw new Error(data.message);
      }
    } catch (err) {
      setError(err.message);
      throw err;
    } finally {
      setSyncing(false);
    }
  };
  
  return { syncMedications, syncing, error };
}

// Usage in component
function MedicationForm() {
  const { syncMedications, syncing } = useMedicationSync(ngrokUrl);
  
  const handleSave = async (medication) => {
    // 1. Save to Lambda/DynamoDB first
    await saveToLambda(medication);
    
    // 2. Then trigger sync to device
    await syncMedications();
    
    // 3. Show success message
    toast.success('Medication saved and synced!');
  };
  
  return (
    <button onClick={handleSave} disabled={syncing}>
      {syncing ? 'Syncing...' : 'Save Medication'}
    </button>
  );
}

================================================================================
RESPONSE FORMAT
================================================================================

Success Response (200 OK):
--------------------------
{
  "status": "success",
  "message": "Medications refreshed from Lambda API",
  "userId": "u_123",
  "syncedCount": 3,
  "action": "synced"
}

Error Response (500):
---------------------
{
  "status": "error",
  "message": "Failed to sync medications: <error details>"
}

Service Not Running (200 OK but status="error"):
-------------------------------------------------
{
  "status": "error",
  "message": "Medication service is not running"
}

================================================================================
WHEN TO CALL THIS WEBHOOK
================================================================================

Call this endpoint AFTER any medication CRUD operation:

1. ✅ After creating a new medication
2. ✅ After updating medication (time, name, photo, etc.)
3. ✅ After deleting a medication
4. ✅ After bulk import/update operations

Example Flow:
-------------
1. User creates medication in web app
2. Frontend saves to Lambda/DynamoDB
3. Lambda returns success
4. Frontend calls: POST /webhook/medications/sync
5. Device immediately fetches updated medications from Lambda
6. Device stores in local SQLite database
7. Medication will trigger at scheduled time

================================================================================
INTEGRATION PATTERNS
================================================================================

Pattern 1: Optimistic Update
-----------------------------
async function updateMedication(medicationId, updates) {
  // 1. Update in Lambda
  await lambda.updateMedication(medicationId, updates);
  
  // 2. Trigger sync (don't wait for response)
  fetch(`${ngrokUrl}/webhook/medications/sync`, { method: 'POST' })
    .catch(err => console.error('Sync failed:', err));
  
  // 3. Show success immediately
  toast.success('Medication updated!');
}

Pattern 2: Wait for Sync
-------------------------
async function updateMedication(medicationId, updates) {
  // 1. Update in Lambda
  await lambda.updateMedication(medicationId, updates);
  
  // 2. Wait for sync to complete
  const syncResult = await fetch(`${ngrokUrl}/webhook/medications/sync`, {
    method: 'POST'
  }).then(r => r.json());
  
  if (syncResult.status === 'success') {
    toast.success(`Medication updated and synced to device!`);
  } else {
    toast.warning('Updated but sync failed. Will retry automatically in 2 hours.');
  }
}

Pattern 3: Batch Operations
----------------------------
async function bulkUpdateMedications(medications) {
  // 1. Update all in Lambda
  await Promise.all(
    medications.map(med => lambda.updateMedication(med.id, med))
  );
  
  // 2. Single sync call for all changes
  await fetch(`${ngrokUrl}/webhook/medications/sync`, { method: 'POST' });
  
  toast.success(`${medications.length} medications synced!`);
}

================================================================================
ERROR HANDLING
================================================================================

Network Errors:
--------------
- If ngrok tunnel is down, request will fail
- Device will auto-sync every 2 hours anyway
- Show warning: "Sync failed, will retry automatically"

Service Not Running:
-------------------
- If medication service is disabled on device
- Response: {"status": "error", "message": "Medication service is not running"}
- Show info: "Device medication service is offline"

Timeout:
--------
- Webhook might take 5-10 seconds (fetching from Lambda)
- Set timeout: 30 seconds
- If timeout, show: "Sync taking longer than expected, device will sync automatically"
