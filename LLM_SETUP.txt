================================================================================
LLM (AI VOICE ASSISTANT) SETUP GUIDE
MediSpecs - OpenAI GPT Integration
================================================================================

🤖 WHAT IS THIS?
--------------------------------------------------------------------------------
Ruby now has AI-powered conversation capabilities using OpenAI GPT-3.5-Turbo.

When you say "Hey Ruby" followed by a question or statement:
- Ruby sends your voice command to OpenAI GPT
- GPT generates a friendly, senior-friendly response
- Ruby speaks the response back to you via TTS

NOTE: Ruby provides information and clarification ONLY.
Ruby CANNOT execute actions, create reminders, or control devices.


🔧 INSTALLATION
--------------------------------------------------------------------------------

Step 1: Install OpenAI Python Library
--------------------------------------
pip install openai

Or install all requirements:
pip install -r requirements.txt


Step 2: Get OpenAI API Key
---------------------------
1. Go to: https://platform.openai.com/api-keys
2. Sign up or log in
3. Click "Create new secret key"
4. Copy the key (starts with "sk-proj-..." or "sk-...")
5. Save it somewhere safe (you can't see it again!)


Step 3: Add API Key to .env File
---------------------------------
Create or edit .env file in your project root:

cd /path/to/medispecs-backend-specs
nano .env

Add this line:
OPENAI_API_KEY=sk-your-actual-api-key-here

Save and exit (Ctrl+O, Enter, Ctrl+X)


Step 4: Verify Configuration
-----------------------------
Check that config.py is set up correctly (should be by default):

LLM_ENABLED = True
LLM_MODEL = "gpt-3.5-turbo"
LLM_SYSTEM_PROMPT = "You are Ruby, a helpful voice assistant..."


📝 CONFIGURATION
--------------------------------------------------------------------------------

Edit config.py to customize LLM settings:

# Enable/disable LLM
LLM_ENABLED = True

# OpenAI API key from .env file
LLM_API_KEY = os.getenv("OPENAI_API_KEY", "")

# Model selection
LLM_MODEL = "gpt-3.5-turbo"  # Fast, cheap (~$0.002/1K tokens)
# LLM_MODEL = "gpt-4"         # Best quality, expensive (~$0.03/1K tokens)

# Ruby's personality and instructions
LLM_SYSTEM_PROMPT = (
    "You are Ruby, a helpful voice assistant for senior citizens. "
    "Be friendly, clear, and concise, super concise, and avoid using "
    "hard jargons and vocabularies, use easy words. "
    "You can only provide information and clarification. "
    "You CANNOT execute actions, create reminders, or control devices."
)

# Fallback message when offline
LLM_FALLBACK_MESSAGE = "I am not connected to internet right now"


🚀 USAGE
--------------------------------------------------------------------------------

Complete Flow:
--------------
1. User: "Hey Ruby"
2. Ruby: "Hey, I am Ruby. How can I help you?" (via TTS)
3. User: "What's the weather like today?"
4. [Voice → STT → Text → LLM → Response → TTS]
5. Ruby: "I'm sorry, but I can't check the weather right now. I can only 
         answer questions with the knowledge I have. Is there something 
         else I can help you with?"

Examples:
---------
✅ Good Questions (Ruby can answer):
   - "Hey Ruby, what is high blood pressure?"
   - "Hey Ruby, how do I check my heart rate?"
   - "Hey Ruby, what should I eat for breakfast?"
   - "Hey Ruby, tell me about diabetes"
   - "Hey Ruby, how many hours of sleep do I need?"

❌ Action Requests (Ruby cannot do):
   - "Hey Ruby, set a reminder for 3pm" → Ruby will say she can't do this
   - "Hey Ruby, call my daughter" → Ruby will say she can't do this
   - "Hey Ruby, turn on the lights" → Ruby will say she can't do this


📡 WHAT HAPPENS BEHIND THE SCENES
--------------------------------------------------------------------------------

Voice Flow:
-----------
1. User says "Hey Ruby"
   → STT detects wake word
   → TTS: "Hey, I am Ruby. How can I help you?"

2. User speaks command (5 seconds)
   → STT records and transcribes
   → Console: 🎤 [TRANSCRIBED] 'your question here'
   → Console: ✅ [COMMAND] 'your question here'

3. Command sent to OpenAI GPT
   → Console: 🤖 [LLM] Processing command: 'your question here'
   → GPT generates response (1-3 seconds)
   → Console: ✅ [LLM] Response received (1.23s)
   → Console: 💬 Ruby: 'response text here'

4. Response spoken via TTS
   → Console: 🔊 [TTS] Speaking response...
   → User hears Ruby's answer

5. Back to listening
   → Console: 🎧 Listening for 'hey ruby'...

🐛 TROUBLESHOOTING
--------------------------------------------------------------------------------

❌ "LLM not available, using fallback"
  → Check OPENAI_API_KEY in .env file
  → Run: python -c "import os; from dotenv import load_dotenv; load_dotenv(); print(os.getenv('OPENAI_API_KEY'))"
  → Should print your key (sk-...)

❌ "Invalid API key" / "Authentication error"
  → API key is wrong or expired
  → Get new key from: https://platform.openai.com/api-keys
  → Update .env file

❌ "Rate limit exceeded"
  → You've used too many requests too quickly
  → Wait 1 minute and try again
  → Consider upgrading your OpenAI account tier

❌ "No internet connection" / Fallback message spoken
  → Check internet: ping google.com
  → Check firewall settings
  → Check if OpenAI API is down: https://status.openai.com

❌ Ruby takes too long to respond
  → GPT-3.5-Turbo usually responds in 1-3 seconds
  → If slower, check internet speed
  → Consider using local LLM (Ollama) instead

❌ Ruby gives incorrect or weird answers
  → This is normal for AI - it's not always perfect
  → Try rephrasing your question
  → Use GPT-4 for better accuracy (but more expensive)

❌ "openai module not found"
  → Install: pip install openai
  → Or: pip install -r requirements.txt
