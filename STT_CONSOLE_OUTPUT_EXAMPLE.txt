🎯 WHAT HAPPENS WHEN
--------------------------------------------------------------------------------
1. User speaks random words
   → Logged with 🎤 [TRANSCRIBED]
   
2. User says "Hey Ruby"
   → 🔔 WAKE WORD DETECTED banner
   → TTS speaks: "Hey, I am Ruby. How can I help you?"
   → Starts recording command
   
3. User speaks command
   → Real-time preview: 💬 Hearing: '...'
   → Captured chunks: ✓ Captured: '...'
   → Final command: ✅ [COMMAND] '...'
   → Logged: 📝 Logged command: ...
   
4. User stays silent after wake word
   → ⚠️ [NO COMMAND] Silence or unclear audio
   
5. Command timeout (5 seconds)
   → Recording ends, processes final result
   → Returns to listening for next wake word
