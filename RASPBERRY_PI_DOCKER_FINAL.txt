================================================================================
❌ IF IT FAILS
================================================================================

### Error: "Failed to import picamera2"

FIX:
docker-compose down
docker-compose build --no-cache
docker-compose up

### Error: "Failed to open camera"

CHECK:
1. Camera enabled: sudo raspi-config -> Interface -> Camera
2. Camera working: libcamera-hello
3. Reboot: sudo reboot

### Error: Build timeout during pip install

FIX:
# Increase timeout (already set to 300s in Dockerfile)
# Or build with more memory: edit /boot/config.txt
# Add: gpu_mem=16
# Then reboot

### Error: "Permission denied" for /dev/video0

FIX:
# Add user to video group:
sudo usermod -aG video $USER
# Logout and login again

================================================================================
🎥 CAMERA ARCHITECTURE IN DOCKER
================================================================================

1. picamera2 library installed via pip in Docker
2. Camera accessed through /dev/video* devices (mapped in docker-compose)
3. Privileged mode allows hardware access
4. RGB format used natively (no BGR conversion for YOLO)
5. Only convert to BGR when encoding JPEG for AWS

Flow:
  picamera2.capture_array() 
  → RGB frame 
  → YOLO processing 
  → Face crop 
  → Convert to BGR 
  → JPEG encode 
  → Send to AWS

⚙️ CONFIGURATION (config.py)
================================================================================

Key settings you might want to change:

FACE_DETECTION_ENABLED = True           # Turn on/off face detection
FACE_DETECTION_FPS = 2                  # How often to check (2Hz = every 0.5s)
FACE_CONFIRMATION_COUNT = 4             # Detections needed (4 * 0.5s = 2s)
FACE_COOLDOWN_SECONDS = 10              # Wait time after recognition
YOLO_CONFIDENCE_THRESHOLD = 0.65        # Confidence level (0-1)

After changing config.py:
docker-compose restart

🔧 DOCKER COMPOSE OVERVIEW
================================================================================

Key configurations:

ports:
  - "8000:8000"                         # API access

devices:
  - /dev/i2c-1:/dev/i2c-1              # OLED display
  - /dev/gpiomem:/dev/gpiomem          # GPIO
  - /dev/video0:/dev/video0            # Camera
  - /dev/vchiq:/dev/vchiq              # Pi Camera interface
  - /dev/video10-12:/dev/video10-12    # Pi Camera ISP

privileged: true                        # Required for hardware
group_add:
  - video                               # Camera access

volumes:
  - ./:/app                             # Code mount (for --reload)
  - db_data:/app/data                   # Database persistence
