================================================================================
MEDISPECS ENVIRONMENT SETUP
================================================================================

Create a `.env` file in the project root with the following variable:

--------------------------------------------------------------------------------
REQUIRED VARIABLES:
--------------------------------------------------------------------------------

# Lambda API Base URL (used for reminders, face recognition, and other functions)
LAMBDA_API_URL=https://zqglpdheqk.execute-api.ap-southeast-1.amazonaws.com/staging


--------------------------------------------------------------------------------
EXAMPLE .env FILE:
--------------------------------------------------------------------------------

# Copy this content to create your .env file

# Lambda API Base URL - All endpoints use this base
LAMBDA_API_URL=https://zqglpdheqk.execute-api.ap-southeast-1.amazonaws.com/staging


--------------------------------------------------------------------------------
AVAILABLE ENDPOINTS:
--------------------------------------------------------------------------------

Using the base URL, the following Lambda endpoints are available:

Reminders:
  - GET  {LAMBDA_API_URL}/reminders
  - POST {LAMBDA_API_URL}/reminders
  - GET  {LAMBDA_API_URL}/reminders/{id}

Face Recognition:
  - POST {LAMBDA_API_URL}/recognize
  - GET  {LAMBDA_API_URL}/family
  - POST {LAMBDA_API_URL}/family


--------------------------------------------------------------------------------
USAGE:
--------------------------------------------------------------------------------

1. Create .env file:
   $ touch .env

2. Add the LAMBDA_API_URL variable to your .env file

3. Restart the service:
   $ docker-compose restart
